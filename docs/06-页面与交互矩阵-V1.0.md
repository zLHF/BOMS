# 商机管理系统 · 页面与交互矩阵（V1.0）

> 用途：定义每个页面的区块、弹窗/抽屉、权限点、状态边界，防止"只做主页面、漏掉关键交互"。
> 视觉与组件遵循《01-设计系统规范》；权限点引用《04-权限码表-V1.0》；接口引用《07-API接口清单-V1.0》；阶段/脱敏规则见《05-决策记录》D1/字段权限 V1.2。
> 范围：V1.0 页面。报价/订单/发票/退款/费用 Tab 为占位（标注"V1.1"）。

---

## 1. 通用状态规范（所有页面适用）

| 状态 | 呈现 | 触发 |
|------|------|------|
| 加载中 | `el-skeleton` 骨架屏 / 表格 loading | 数据请求中 |
| 空态 | `el-empty` + 引导（如"新增第一个商机"） | 列表无数据 |
| 无操作权限 | 按钮**隐藏**（`v-perm`）；只读字段灰显 | 缺操作权限码 |
| 越权访问 | `403` → `el-result` 或 toast，跳回有权页 | 访问范围外/他租户对象 |
| 校验失败 | 表单字段级红字 + 顶部汇总 | 必填/格式/阶段必填 |
| 字段脱敏 | 手机号 `138****8888` 等 | **V1.2 实现**，V1.0 默认明文，仅预留渲染位 |
| 占位 Tab | 灰显 + "该能力将于 V1.1 上线" | 报价/订单/发票/退款/费用/工单 |

## 3. 表单 / 弹窗 / 抽屉规范（补设计系统）

### 3.1 表单态

| 态 | 规则 |
|----|------|
| 必填 | label 前红 `*`；失焦即时校验 |
| 错误 | 字段下红字 + 输入框红框；提交时顶部汇总滚动定位 |
| 禁用 | 无权限/不可编辑字段灰显 `disabled` |
| 只读 | 协作"仅查看"、详情查看态用纯文本展示 |
| 脱敏 | V1.2；V1.0 预留渲染槽位，默认明文 |

### 3.2 弹窗 / 抽屉

| 类型 | 宽度 | 按钮位 | 备注 |
|------|------|--------|------|
| 详情抽屉（商机） | 420px（设计系统 §3） | 底部操作区 3 列 | 右侧滑出 |
| 表单弹窗（新建/编辑联系人等） | 600px | 右下"取消/确定" | |
| 危险确认（删除/转移/移公海/回退） | 420px | 右下，主操作用 `type=danger` | **二次确认 + 影响说明**（如转移会通知相关人） |

### 3.3 图表（ECharts）

| 图 | 用途 | 空数据 |
|----|------|--------|
| 销售漏斗 | 工作台/详情阶段分布 | 占位"暂无商机数据" |
| 趋势/排行 | 工作台团队排行 | 占位灰条 |
