# 商机管理系统 · 设计系统规范

> 来源：从高保真原型 `business-opportunity-highfi-vue3/src/styles.css` 提炼，作为正式工程的视觉与组件基线。
> 组件库：Element Plus + `@element-plus/icons-vue` + ECharts。
> 适用：以高保真原型为基座重构后的全部前端页面，新页面必须复用本规范定义的 token 与模式，不允许散落硬编码颜色/间距。

---

## 1. 设计 Token

### 1.1 颜色

**Element Plus 主题对齐**：`--el-color-primary` 覆盖为 `#2563eb`，与 `--blue` 一致。

### 1.2 圆角 / 阴影 / 间距

| 变量 | 值 | 用途 |
|------|------|------|
| `--radius` | `18px` | 卡片/面板统一圆角 |
| `--shadow` | `0 12px 32px rgba(15,23,42,.08)` | 卡片悬浮阴影 |

派生圆角（规范化后建议补齐）：

- 大容器：`18px`（卡片、面板、表格卡）
- 中控件：`12–14px`（标签、输入框容器、KPI 图标 16px、详情信息块 14px）
- 胶囊：`999px`（阶段步骤条、徽标、头像计数）
- Logo 标记：`11px`（小）/ `17px`（登录大号）

间距基准走 4px 栅格：页面主区 padding `22px 26px 34px`；卡片内 padding `18–24px`；栅格间距 `gutter=16/20`。

## 2. 布局骨架

整体为「固定侧边栏 + 吸顶顶栏 + 滚动内容区」三段式。

```
┌──────────┬───────────────────────────────────────────┐
│          │  topbar (h=68, sticky, blur)               │
│ sidebar  ├───────────────────────────────────────────┤
│ (w=244)  │                                            │
│ fixed    │  page-body (padding 22/26/34)              │
│ blur     │   ├ page-head (面包屑 + H1 + 操作区)       │
│          │   ├ kpi-grid / filter-card                 │
│          │   └ table-card / panel / detail-layout     │
└──────────┴───────────────────────────────────────────┘
```

### 2.1 侧边栏 `.sidebar`

- 宽 `244px`，`position:fixed`，半透明白 `rgba(255,255,255,.92)` + `backdrop-filter:blur(16px)`，右侧 1px 边框。
- 顶部 `.brand`（高 68px，Logo 渐变方块 `linear-gradient(135deg,#1d4ed8,#38bdf8)` + 系统名）。
- 中部 `.nav-scroll` 可滚动，按 `nav-group` 分组（核心业务 / 销售协同 / 交易履约 / 平台管理），每组有 `.nav-title`（12px 灰）。
- `.nav-item` 高 42px，hover 淡蓝底；`.active` 状态：左侧 3px 蓝色内阴影条 + 蓝字加粗 + 浅蓝渐变底。可带右侧徽标 `em`（如商机数 `128`）。
- 底部 `.sidebar-foot`：「仅本租户可见」「按权限查看」「版本号」。

### 2.2 顶栏 `.topbar`

- 高 68px，`position:sticky`，半透明 + blur，底部 1px 边框。
- 左：`.tenant-switch` 租户切换（白底圆角胶囊 + `当前租户` success tag + 下拉箭头）。
- 中：`.global-search` 全局搜索（最大宽 520px，`prefix-icon=Search`，append `⌘K`）。
- 右：`.top-actions` 通知 badge / 帮助 / 设置 圆形按钮 + `.user-chip` 用户卡（头像 + 姓名 + 角色）。

### 2.3 内容区 `.main-shell` / `.page-body`

- `margin-left:244px`，`min-height:100vh`。
- `.page-head`：左侧面包屑（如 `商机管理 / 全部商机`）+ H1（带「仅本租户可见」浅色 tag）+ 描述；右侧 `.head-actions` 操作按钮组。

### 2.4 响应式断点

| 断点 | 行为 |
|------|------|
| `≤1280px` | sidebar 缩到 220px；KPI 6→3 列；dashboard/detail 单列；contact 单列；登录隐藏右侧 hero |
| `≤900px` | sidebar 隐藏；主区 `margin-left:0`；topbar 换行；KPI 1 列；表格字号降到 12px；page-head 竖排 |

### 3.1 关键样式模式

- **卡片家族** `.filter-card/.table-card/.panel/.form-card/.tabs-card/.side-panel/.upload-card/.customer-hero`：统一 `--card` 背景 + `--line` 边框 + `--radius` 圆角 + `--shadow`。
- **阶段标签** `.stage`：胶囊，按阶段分色（见下表），用于商机阶段、状态展示。
- **数据表** `.data-table`：表头 `#f8fafc` 底、12px 加粗灰字；行 hover/选中 `#eff6ff`；单元格 `padding:14px 12px`、`white-space:nowrap`。
- **头像堆叠** `.avatar-stack`：协作人多头像负 margin 叠加 + `+N` 计数。
- **步骤/阶段条** `.steps/.stage-bar`：5 等分胶囊，`done`（青）/ `active`（蓝实心）/ 未达（灰）。
- **时间线** `.timeline/.activity`：左侧蓝点 + 内容，跟进与操作日志通用。
- **漏斗** `.funnel`：宽度按 `--w` 变量驱动的渐变条（蓝→青）。

## 4. 交互与权限呈现规范

1. **数据范围标识**：列表/详情统一带「仅本租户可见」浅色 tag，呼应多租户隔离（PRD 4.2）。
2. **权限指令**：按钮级权限用自定义指令 `v-perm="'opp:transfer'"` 控制显隐/禁用（工程化新增，见架构文档）；高保真中所有操作按钮均需挂权限码。
3. **字段脱敏**：手机号、金额、毛利等敏感字段按角色显示明文/脱敏/隐藏（PRD M04-03），前端按字段权限渲染 `138****8888`。
4. **空态 / 加载态 / 错误态**：当前高保真为静态 Mock，工程化需补齐 `el-empty`、骨架屏 `el-skeleton`、`el-result` 错误页。
5. **筛选视图保存**：列表页筛选区支持「保存筛选视图」（PRD M05-01），需在 FilterCard 上预留入口。
6. **列配置**：表格工具栏「自定义列」需落地为可勾选列 + 本地持久化。

## 5. 工程化迁移要点（基座重构）

| 当前高保真做法 | 工程化目标 |
|----------------|------------|
| 全部组件内联在单个 `App.vue` 的 `defineComponent` | 拆分为独立 `.vue` SFC，按 `views/components/layouts` 归类 |
| `currentPage` ref 字符串模拟路由 | Vue Router 4，路由表对应菜单 `menu`，带权限 meta + 路由守卫 |
| 硬编码 Mock 数组 | Pinia store + `services/` API 层（先 Mock，后接真实接口），TypeScript 类型定义 |
| 全局 `styles.css` 一行压缩 | 拆为 `tokens.css` + `base.css` + 组件级 `<style scoped>`；Element Plus 主题变量覆盖 |
| `vue/dist/vue.esm-bundler.js` 运行时编译 | 改用 `<template>` 块的 SFC，去掉运行时编译依赖 |
| 无 TS | 全量 TypeScript + `vue-tsc` 类型检查 |

> 重构必须**保持视觉零回退**：先抽 token → 搭骨架（Layout/Router）→ 逐组件迁移并对比截图，确保像素一致后再替换 Mock 为接口。
