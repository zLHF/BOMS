# 商机管理系统 · 文档索引

多租户、多用户的 B2B 商机与客户经营平台设计文档。基于《商机管理系统 PRD 多用户多租户版 V1.0》，UI 以高保真原型（`business-opportunity-highfi-vue3`）为基座。

技术栈：前端 Vue3 + TS + Element Plus + ECharts；后端 Spring Boot 3 + MyBatis-Plus + MySQL 8 + Redis + 对象存储。

## 阅读顺序

**新成员上手**：01 → 02 → 03（先懂视觉、架构、节奏）。

**后端开发**：04 → 09 → 10 → 07 →（05 看决策）。

**前端开发**：01 → 06 → 07 → 04（权限码）。

**测试**：08 → 04 → 07。

**产品/业务确认**：05（重点看 🟡 待追认项）→ 03。
