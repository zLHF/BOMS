# 商机管理系统 · 验收测试用例（V1.0）

> 用途：把《03-分阶段开发计划》的质量门禁和《02-架构》验收基线落成可执行用例。
> 引用：权限码《04》、接口《07》、决策《05》、页面《06》。
> 编号段：1xx 多租户隔离 / 2xx 权限与数据范围 / 3xx 商机闭环 / 4xx 导入 / 5xx 附件 / 6xx 审计 / 7xx 协作对象级 / 8xx 配置 / 9xx 性能。
> 每个里程碑（M1–M3）合并前，对应段用例必须全绿。

## 1xx · 多租户隔离（M1 门禁，最高优先级）

| 编号 | 场景 | 前置 | 步骤 | 预期 | 关联 |
|------|------|------|------|------|------|
| TC-101 | 跨租户访问商机详情 | 租户A用户、租户B有商机X | A 用户带自己 token 请求 `GET /opportunities/{X}` | `403`，并写一条越权审计 | `opp:view`、租户隔离 |
| TC-102 | 跨租户访问客户 | 同上 | A 请求 B 的 `GET /customers/{id}` | `403` + 越权审计 | `customer:view` |
| TC-103 | 附件签名 URL 跨租户 | B 的附件签名下载 URL | A 用户打开该 URL | 拒绝下载（签名校验租户+权限） | `file:download`、M16 |
| TC-104 | 跨租户导出 | A 篡改请求参数指向 B 数据 | `GET /opportunities/export` | `403`，不返回 B 数据 | `opp:export` |
| TC-105 | 全局搜索隔离 | A/B 各有同名客户 | A 全局搜索 | 仅返回 A 租户数据 | PRD 12 |
| TC-106 | 缓存不串租户（白盒） | A/B 同 key 业务 | 检查 Redis key | key 含 `tenant_id` 前缀，互不命中 | 架构 2.2 |

## 2xx · 权限与数据范围（M1 门禁）

| 编号 | 场景 | 前置 | 步骤 | 预期 | 关联 |
|------|------|------|------|------|------|
| TC-201 | 销售仅本人商机 | SALES，data_scope=SELF | `GET /opportunities?view=mine` | 仅返回 owner=自己 的商机 | `opp:view` |
| TC-202 | 无下属权限访问下属商机 | SALES 无 `opp:view:sub` | 访问"下属商机"Tab / `view=sub` | 菜单项隐藏或列表为空 + 接口 403 | `opp:view:sub`、TC映射 06 |
| TC-203 | 主管见下属数据 | SALES_MANAGER，DEPT_AND_SUB | `GET /opportunities?view=sub` | 返回本部门及下级商机 | 数据范围第3节 |
| TC-204 | 无导出权限调用导出 | SALES 无 `opp:export` | 直接调 `GET /opportunities/export` | `403` + 写越权审计 | `opp:export`、评审示例 |
| TC-205 | 无删除权限 | SALES 无 `opp:delete` | 界面无删除按钮；直接调 `DELETE` | 按钮隐藏 + 接口 403 | `v-perm` + 后端校验 |
| TC-206 | 审计员只读 | AUDITOR，data_scope=TENANT | 尝试任意写操作（新增商机/改客户） | 全部 403；`audit:view` 可读全租户日志 | 决策 D4 |
| TC-207 | 配权实时生效 | TENANT_ADMIN 改 SALES 角色权限 | SALES 重新登录 | 新权限/菜单生效 | M04-01 |

## 3xx · 商机全流程闭环（M3 / V1.0 验收核心）

| 编号 | 场景 | 步骤 | 预期 | 关联 |
|------|------|------|------|------|
| TC-301 | 新增商机 | `POST /opportunities` 填必填 | 创建成功、进入初始阶段(prospecting)、生成编号、写审计 | D1、`config:number` |
| TC-302 | 写跟进 | `POST /opportunities/{id}/follows` | 时间线新增、最后跟进时间更新、写审计 | `opp:follow:create`、M07-01 |
| TC-303 | 阶段推进缺必填 | 推进到"方案报价"但缺联系人/报价信息 | `400` 返回缺失字段清单，阶段不变 | PRD 10.1、`config:stage` |
| TC-304 | 成交 | `POST /opportunities/{id}/win` 填金额/时间 | 生成成交记录、进成交列表、写审计 | `opp:win`、D1 |
| TC-305 | 输单 | `POST /opportunities/{id}/lose` 填原因/竞品/复盘 | 进历史状态、不计在途漏斗、写审计 | `opp:lose`、D1 |
| TC-306 | 阶段回退限主管 | SALES 调 rollback → 403；SALES_MANAGER 调 → 成功 | 仅主管/管理员可回退且留痕 | `opp:stage:rollback`、D1 |
| TC-307 | 转移商机 | `POST /opportunities/{id}/transfer` | 归属变更、通知相关人、写审计 | `opp:transfer`、PRD 11 |
| TC-308 | 报价/订单 Tab 占位 | 打开商机详情报价/订单 Tab | 显示"V1.1 上线"，不计入 V1.0 闭环 | 冲突1、06 §1 |
