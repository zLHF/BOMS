# 商机管理系统高保真 Vue 3 原型

这是按高保真 SaaS 产品演示标准重做的商机管理系统前端原型，覆盖登录、工作台、全部商机、新增商机、批量导入、商机详情、客户详情、跟进记录、短信中心、报价管理、订单管理、费用管理、成交商机、租户管理、组织用户、角色权限、操作日志等页面。

## 运行

```bash
npm install
npm run dev
```

## 技术栈

- Vue 3
- Vite
- Element Plus
- @element-plus/icons-vue
- 纯 Mock 数据，无后端依赖

## 设计重点

- 复刻前一版高保真图片的视觉方向：白色卡片、蓝色主色、右侧商机详情抽屉、KPI、筛选区、表格、协作头像、阶段进度。
- 补齐多租户、多用户、组织权限、字段权限、操作日志等管理页面。
- 当前版本用于演示和评审，后续可拆分 Vue Router、Pinia、接口请求和权限守卫。
