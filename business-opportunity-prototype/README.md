# 商机管理系统 Vue 3 原型

这是基于《商机管理系统 V1.0 使用说明书》和多用户、多租户 PRD 扩展出来的前端高保真原型。

## 运行方式

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址即可。

## 覆盖页面

- 登录页
- 工作台
- 商机管理：全部商机、我负责的、我协作的、我关注的、下属商机、下属协作、商机池、成交商机、商机详情、添加商机、批量导入、添加协作、发送短信、商机跟进
- 客户管理：客户列表、客户详情、联系人、下级客户、联系/跟进/任务/工单/商机/订单/发票/退款/费用/附件/归属/日志
- 报价管理、订单管理、费用管理、短信中心、协作中心、报表分析
- 多租户与系统设置：租户管理、组织架构、用户管理、角色权限、数据权限、操作日志、参数配置

## 说明

当前为静态前端原型，数据均为 Mock。后续可接入真实 API、路由、权限守卫和组件库。
